# Univer AI — Бэкенд (Groq Edition)


AI-консультант + рекомендательная система + база с отзывами студентов для абитуриентов Кыргызстана.

## 🔄 Что изменилось: переход с Gemini на Groq

| | Было (Gemini) | Стало (Groq) |
|---|---|---|
| Лимит запросов в день | **20** (бесплатный тариф) | **14,400** |
| Скорость ответа | 15-30 секунд | **1-2 секунды** |
| Модель чата | gemini-flash-latest | **llama-3.3-70b-versatile** |
| Модель парсера | gemini-flash-latest | **llama-3.1-8b-instant** |
| Нужна карта | Нет | Нет |
| Время на парсинг 61 вуза | Не успевает за день | **~10 минут** |

## 🚀 Запуск с нуля (по шагам)

### Шаг 1. Получи Groq API ключ (1 минута, бесплатно, без карты)

1. Открой https://console.groq.com
2. Войди через Google или GitHub
3. В меню слева: **API Keys** → **Create API Key**
4. Назови ключ (например `univer_ai`) → **Submit**
5. Скопируй ключ (начинается с `gsk_...`) — он показывается **только один раз**

### Шаг 2. Удали старую папку venv (если она была от Gemini)

В папке проекта:
```bash
# Windows
rmdir /s /q venv

# Mac/Linux
rm -rf venv
```

Это нужно, потому что меняется зависимость (`groq` вместо `google-generativeai`).

### Шаг 3. Создай новое окружение и поставь зависимости

```bash
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # Mac/Linux

pip install -r requirements.txt
```

### Шаг 4. Настрой .env

```bash
copy .env.example .env         # Windows
# cp .env.example .env         # Mac/Linux
```

Открой `.env` в блокноте и впиши свой ключ:
```
GROQ_API_KEY=gsk_твой_ключ_здесь
DATABASE_URL=sqlite:///./data/univer.db
```

### Шаг 5. Удали старую БД (она была от Gemini-версии)

```bash
# Windows
del data\univer.db

# Mac/Linux
rm data/univer.db
```

### Шаг 6. Залей стартовые 10 вузов (для быстрого старта)

```bash
python seed.py
```
Должно вывести: `Залито 10 вузов с их специальностями.`

### Шаг 7. Запусти сервер для проверки

```bash
uvicorn app.main:app --reload
```

Открой в браузере: **http://localhost:8000/docs**

### Шаг 8. Запусти массовый парсинг всех 61 вузов

⚠️ Сервер можно не останавливать — парсинг идёт в отдельном процессе. Открой **новое окно терминала**, активируй venv и запусти:

```bash
# Активировать venv в новом окне
venv\Scripts\activate

# Сначала тест на 3 вузах (1-2 минуты)
python parse_all.py --limit 3

# Если ок — полный парсинг (8-15 минут)
python parse_all.py

# Если что-то прервалось — продолжить с того же места
python parse_all.py --skip-existing
```

### Шаг 9. Проверь что в БД

```bash
python parse_utils.py status
```

Покажет сколько вузов, специальностей и отзывов у тебя в базе.

## 🧪 Сценарий полного тестирования (10 минут)

В Swagger UI (http://localhost:8000/docs) выполни по порядку:

### 1. Регистрация
**`POST /users/`** → **Try it out**
```json
{"name": "Айбек", "email": "aibek@test.kg"}
```
Получишь `"id": 1`. Запомни.

### 2. Анкета
**`PUT /users/1/profile`** → **Try it out**
```json
{
  "ort_score": 195,
  "gpa": 4.5,
  "budget_kgs": 100000,
  "city": "Бишкек",
  "target_field": "IT",
  "interests": ["программирование", "математика"],
  "languages": ["русский", "английский"]
}
```

### 3. Чат с ботом (теперь отвечает за 1-2 секунды!)
**`POST /chat/message`**
```json
{"user_id": 1, "message": "Привет! Куда мне поступать?"}
```

Отправь ещё:
```json
{"user_id": 1, "message": "А какой из них лучше для будущей работы?"}
```
Бот вспомнит контекст — это и есть память.

### 4. Главная фича: рекомендации
**`GET /recommendations/1?top_n=10`** → **Execute**

Получишь топ-10 специальностей с процентами и обоснованиями.

### 5. 🔥 KILLER FEATURE: AI обосновывает с отзывами
**`GET /recommendations/1/{specialty_id}/argument`**

Возьми `specialty_id` из топа рекомендаций (например `1`) и подставь. AI даст развёрнутое обоснование, цитируя отзывы студентов.

### 6. Дашборд для фронта
**`GET /stats`** → статистика по всей базе

### 7. Просмотр отзывов
**`GET /universities/1/reviews`** → отзывы по первому вузу

## ⚠️ Известные ограничения

- **Отзывы — синтетические.** В Кыргызстане нет агрегатора отзывов о вузах. AI генерирует их на основе публичной информации, все помечены `source="ai_generated"`. На жюри говорим честно: "для прода будем агрегировать Google Reviews, Telegram-каналы абитуриентов и форму с модерацией".
- **Часть вузов может не спарситься** — некоторые сайты лежат или защищены от ботов. Это нормально, такие вузы помечены `parse_status="failed"`.
- **Авторизация без пароля** — для хакатона достаточно.
- **"Шанс поступления" — это эвристика, не ML-модель.** У нас нет датасета "абитуриент → поступил/не поступил" для обучения. Простая работающая модель лучше сложной нерабочей.

## 🛠️ Команда команде

**Для фронта:**
- Бэкенд: `http://localhost:8000`
- Swagger: `/docs`
- CORS открыт — стучитесь с любого origin

**Для девопса:**
- Стек: Python 3.10+, FastAPI, SQLAlchemy, SQLite
- Запуск: `uvicorn app.main:app --host 0.0.0.0 --port 8000`
- Env: один ключ `GROQ_API_KEY`
- БД: файл `data/univer.db`. Для прода — переключить `DATABASE_URL` на Postgres, код не меняется

**Для всей команды через Git:**
- Файл `data/univer.db` можно коммитить — так команда сразу получит все данные парсинга
- ⚠️ Файл `.env` в `.gitignore` — НЕ коммитить! (там твой Groq ключ)
